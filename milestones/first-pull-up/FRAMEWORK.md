## Approved direction

- Goal: one overhand dead-hang pull-up from still, straight arms and feet off the floor; chin clears the bar without kicking, swinging, or craning the neck; controlled return to straight arms.
- Capability-based and suitable across genders; no gender questionnaire.
- Concurrent assisted repetitions, slow lowerings, and brief holds. No compulsory successive hang/row stages.
- Counterweighted assisted machine, feet-supported practice, and optional band assistance.
- Higher machine assistance makes the movement easier. Record the units and repeatable setup. Different machines and bands are not interchangeable loads.
- No unsupported dead-hang entry requirement. Training assistance can remain during the entire descent.
- Body control and movement practice matter; no compulsory weight-loss gate and no first-pull-up deadline.
- Human coaching voice, plain terms, no decorative em dashes, forced contrasts, unsupported superiority claims, or AI-detector promises.
- No 6/6/6 target sequence.
- Preserve device-local saving, portable backup, curated logs, personal certificate, celebration, and honest pause handling from the push-up framework.

## Implemented programming choices for review

These numerical rules are coaching choices, not thresholds validated in a beginner trial.

| Item | Rule |
| --- | --- |
| Frequency | Default twice weekly with at least a day between; once-weekly option follows the same order |
| Warm-up | A few minutes easy movement, gentle arm movement, 1–2 generously assisted reps, then rest |
| Check | Up to 3 assisted repetitions; no preselected effort or rep result |
| Accept | 3 controlled reps, easy or about 2 more available |
| Too hard or position changes | More assistance, rest, retry; at most 3 attempts per local calendar day, retained across reloads |
| Accepted check | Counts as set 1 that day; the remaining work is set 2 and the small lowering dose |
| Main work | 2 sets, initially 3/3 reps, about 2 minutes rest or longer as needed |
| Holds/lowerings | 2 sets of 1 assisted lowering, ~1 second top hold, ~3 second descent, ~2 minutes rest |
| Add reps | Meet both targets with easy/controlled effort: add 1 rep to the smaller set, capped at 5/5 |
| Less assistance | 5/5 controlled in 2 sessions offers a recheck; easy can offer an earlier recheck; staying still adds reps |
| One position issue | Repeat targets; no wipe of earned rep targets |
| Two consecutive position issues | Recheck assistance |
| Hard or incomplete work | Repeat targets; offer more rest/assistance |
| Equipment change | Log the change in notes, then recheck; labels alone do not automatically reset progress |
| Pain/unsure | Stop; retain form/history; pause progression; no instant loss of the log form on a radio tap |
| Return after 14 days | Offer 3/3 with a fresh assistance check, or 1/1 if already practicing unassisted |
| Review | Every 8 saved sessions with pain=no and some reps completed; calendar time is not completion |
| After first rep | Optional 1/1 unassisted practice, adding 1 rep per controlled session toward 3/3; replaces assisted sets and extra lowerings |

The assisted route entails 6–10 full repetitions plus 2 extra controlled descents per session, including the first day's accepted check within the main reps. The holds are combined with those descents, not additional full sets. Warm-up reps and unsuccessful checks add exposure; avoid repeated checks to chase a result. A hard check sequence can be the whole session.

For existing pulling programs, substitute the guide's work for usual pull-up/pull-down work rather than stack it on top. Rows are supporting work already present in a broader program; the draft does not add mandatory rows. No-equipment visitors get an honest preparation/off-ramp to the Hub, not a promise of a complete bar-free pull-up route.

## Screens and behavior

Start → equipment/assistance → movement check → workout → progress. Separate milestone confirmation and completion screens. URL hashes support browser Back and reload. Coaching help is beside the check and log; the navigation stays reachable. Goal-position SVG is illustrative and is not a machine/band safety demonstration.

The machine setting is a free-text record, not a calculated bodyweight reduction. Foot assistance is qualitative. Progress only compares work at a repeatable setup. The app does not auto-decrease machine weight or equate band colors.

No account, email capture, backend, video upload, automatic calendar reminders, or payment flow. Browser data is not sent to Bryan. A browser backup is necessary for device transfer and possible storage clearing.

## Data contract

One self-contained HTML file; no external JavaScript or fonts. Storage key `bfit-first-pullup-v1`; schemaVersion=1 and guide=first-pull-up. Push-up backups are rejected.

Profile records method, setting, name (reserved optional identifier), existing-training mode, and weekly frequency. Records include targets, completed reps, date, effort, pain response, lowering sets, notes, and whether unassisted. Starting checks remain separately visible. Inputs autosave. Earlier unfinished workout entries are archived when switching to a newly checked setup or unassisted practice. Backup restore validates and asks before replacing the current record.

Export: plain-language training TXT, complete JSON backup, and a name/date certificate PDF generated in-browser. Certificate is a self-reported achievement, not a professional qualification. No empty identity fields in a downloaded certificate.

## Evidence and competitor audit

- Vigouroux & Devise (2024), https://pubmed.ncbi.nlm.nih.gov/38247962/: 30 advanced/high-elite climbers, five weeks, twice weekly; contraction-specific training improved aspects of pulling performance. Indirect support for holds/lowerings, not a zero-to-first-pull-up trial.
- Piper and colleagues, https://strengthandconditioning.org/jasc-31-3/3828-original-scientific-research-study-the-effects-of-elastic-band-assistance-during-pull-ups: 33 participants, acute assistance protocols increased repetitions. Abstract reviewed; full paper member-restricted. Not evidence that bands accelerate a beginner's first pull-up.
- Nerd Fitness, https://www.nerdfitness.com/blog/do-a-pull-up/: useful demonstrations and multiple assistance options. Avoid importing a 30-day promise or blanket weight-loss requirement.
- StrongFirst, https://www.strongfirst.com/progress-first-pull/: useful position/hold emphasis. Weighted hangs and hollow-rocker prerequisites are not defaults here.
- ACE, https://www.acefitness.org/resources/pros/expert-articles/5565/4-moves-to-help-you-master-the-pull-up/: assistance and lowering examples. Do not copy generic 8–12-rep advice onto beginner negative sets.

Research supports ingredients, not our exact formula, universal timelines, or superiority over competitors.

## Approved follow-up changes: November 25, 2026

This section supersedes conflicting earlier draft details.

- Onboarding now asks equipment, assistance description, and pain status. Weekly frequency and existing-training questions were removed. Existing-training integration is explained beside the workout.
- Equipment choices distinguish a bar without assistance from no suitable pulling equipment. The first gets guidance on arranging stable foot support; the second gets a clear equipment requirement and preparation route. Neither promises equipment-free pull-up achievement.
- One existing lowering set can use a stable-platform-to-top technique. Start feet-supported; reduce leg help gradually; only lift the feet when descent and exit can be controlled. Log usual setup, supported, controlled without help, or needed more help. No extra sets are added.
- Coaching readiness checkpoint: comfortable still hanging plus roughly three seconds lowering without help through the full range. It is not a validated predictor or mandatory prerequisite for documenting an already achieved repetition.
- A first unassisted attempt is one replacement working set. The 'I tried one; continue with assistance' control assigns just the remaining assisted set and skips additional lowerings. No repeat all-out attempts.
- Machine reductions use the smallest available step. Feet and bands use a repeatable small change, not fabricated pound equivalents.
- A harder-check attempt can return to the previous accepted assistance and targets. One check consumes one of today's two working sets; two or more finish today's practice. Recovery work does not advance normal targets. Pain removes this shortcut and requires the pause pathway.
- Observable full-range, quiet-leg, controlled-descent cues lead effort choices. About two remaining repetitions stays as a supporting workout cue.
- Eight-session reviews can be acknowledged, with dated review history retained. The panel no longer reopens on every subsequent session after eight.
- Training logs have a selectable-text fallback. Timer uses role=timer and aria-live=off; completion uses the existing status announcement.
- Certificate now states the non-expiring technique-review voucher, paused intake, Hub location, and one-review-per-person terms.
- Added page description, Open Graph text, Twitter summary metadata, and an inline favicon. Draft banner and noindex deliberately remain until publication. A verified sharing image and final canonical URL remain release tasks.
