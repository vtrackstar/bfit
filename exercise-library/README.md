# BFit Exercise & Movement Library

The canonical public library is [Exercise & Movement Library](https://vtrackstar.github.io/bfit/exercise-library/), published as part of `vtrackstar/bfit` through GitHub Pages.

This source was migrated from the archived BFit Library v6 package dated 2026-10-30. Its embedded static catalog and `catalog.json` both contain **231 written-reviewed movement records** (226 existing approved entries plus five new mobility definitions; no new demonstration approvals), with stable `BFIT-xxxxx` IDs. Do not renumber IDs or change their anchor fragments. Deep links such as `#BFIT-00126` must continue to open the same movement.

The self-contained page embeds a reviewed fallback catalog; `app.js` also checks the published same-origin `catalog.json` through `feed-config.js` and `catalog-feed.js`. The embedded fallback works even if that request fails. The CSV parser is retained for future use. If live feed access fails, the page should explicitly indicate that its saved catalog is being shown. New data is not automatically committed to GitHub; update the reviewed snapshot and embedded copy together when making a release.

The editorial source of truth is the Google Sheet **BFit Exercise & Movement Library — Living Master**. The public feed is **BFit — Public Approved Exercise Feed**. The writable editorial master is https://docs.google.com/spreadsheets/d/1xtxh9ey80FL0rFEi7dCHTfapFa2f7BHZhK-BsDiMuqM/edit; retain the original as a historical backup. The old Google Sheets feed is read-only to the current account (write returned 403). A writable, private approved-only spreadsheet copy holds 231 records, matching the repository. The public website now refreshes from the repository JSON rather than the old 226-record feed. Do not point the website at a private spreadsheet; future updates must commit the approved JSON and embedded copy together. Demonstration videos remain under review; the library does not present unapproved videos as verified.

For release checks, verify searching, category and difficulty filters, reset, copied deep links, direct visits to BFIT ID anchors, the empty-result state, mobile layout, and read-only catalog refresh. Keep the original off-repo site available until the new path and references have been checked publicly; GitHub cannot redirect links on the original chatgpt.site host.
